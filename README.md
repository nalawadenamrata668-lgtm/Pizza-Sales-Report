# 🍕 Pizza Sales Analysis Dashboard

An interactive Power BI dashboard developed to analyze pizza sales,
orders, revenue, customer preferences, and product performance.

## 📌 Project Overview

This project analyzes pizza sales data using Microsoft Power BI.
The dashboard provides insights into sales performance, order trends,
pizza categories, pizza sizes, and best- and worst-selling products.

## 🎯 Business Problem

The pizza business needs a simple way to understand its sales
performance and identify customer ordering patterns.

The dashboard helps answer questions such as:

- How much revenue is generated?
- How many orders and pizzas are sold?
- Which pizza categories are most popular?
- Which pizza sizes are preferred?
- Which pizzas are the best sellers?
- Which pizzas are underperforming?
- How do orders change over time?

## 📊 Key Performance Indicators

- Total Revenue
- Average Order Value
- Total Pizzas Sold
- Total Orders
- Average Pizzas Per Order

## 📈 Dashboard Visualizations

### 1. Daily Trend for Total Orders
Shows the number of orders received each day.

### 2. Monthly Trend for Total Orders
Shows the change in total orders across months.

### 3. Percentage of Sales by Pizza Category
Shows the contribution of each pizza category to total sales.

### 4. Percentage of Sales by Pizza Size
Shows customer preferences for different pizza sizes.

### 5. Total Pizzas Sold by Pizza Category
Compares the number of pizzas sold across categories.

### 6. Top 5 Best-Selling Pizzas
Shows the top 5 pizzas based on revenue, quantity, and orders.

### 7. Bottom 5 Performing Pizzas
Shows the bottom 5 pizzas based on revenue, quantity, and orders.

## 🧹 Data Preparation

The pizza sales data was prepared using SQL and Power Query before
building the Power BI dashboard.

The main steps included:

- Importing the pizza sales dataset into SQL
- Exploring and understanding the data using SQL queries
- Cleaning and transforming the data
- Checking for missing or incorrect values
- Performing data aggregation using SQL
- Preparing the required data for Power BI
- Creating additional transformations using Power Query
